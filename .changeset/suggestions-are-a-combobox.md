Web UI: the message box's `@` mention list and `/` command list are a combobox with a listbox. While a list shows, the box names the highlighted suggestion as its active option, so a screen reader announces it while focus stays in the box. The keys stay as they were: ↑/↓ move, Enter or Tab picks, Escape closes the list and keeps the text.
