Web UI: `?` (when you aren't typing in a box) or Ctrl/Cmd+/ (anywhere) opens a list of every keyboard shortcut, grouped by where it applies (Everywhere, Inbox row, Profile panel, Message box, Search box), each naming its keys as your platform shows them (⌘ and ⌥ on a Mac). Escape closes it and puts focus back where it was. The list is generated from the keymap, so every key added later appears in it.
