Web UI: a channel's messages, a thread's replies and an Inbox conversation's messages are each one Tab stop. ↑/↓ or k/j move one message, Home and End go to the first and last loaded message, and ↑ past the oldest loaded message loads older ones, keeping focus where it was. A fold of closed threads is one item in the list, and Enter unfolds it. Tab from a message walks its own links and buttons, then leaves the list. Screen readers hear each list as a feed, and each message by its author and time.
